# YeBetWeg Memory Bank

This directory is the project’s persistent memory bank for humans and AI agents.

## File Map
- core/project_context.md: product definition, users, pillars, implementation reality, and source-of-truth rules
- development/development_plan.md: active development plan and near-term priorities
- notes/project_notes.md: implementation observations, risks, and working notes
- security/project_rules.md: rules, conventions, and guardrails
- status/progress_tracker.md: current status and milestone summary
- updates/changelog.md: recent changes and upcoming milestone focus

## How to Use This Folder
1. Start with core/project_context.md for the product and architecture overview.
2. Use development/development_plan.md for the active delivery plan.
3. Check status/progress_tracker.md before starting or resuming work.
4. Update the relevant memory file whenever scope, architecture, or priorities change.

## Important Rule
Treat this folder as the shared source of truth for planning and execution. When a memory file and the live code disagree, prefer the live code and update the memory file accordingly.
